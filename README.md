# 🧮 2009 Federal Income Tax Calculator [A COS 201 Project]

![Python](https://img.shields.io/badge/Python-3.x-blue)
![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)

A Python program to compute U.S. federal personal income tax for the year **2009**, based on IRS tax brackets.  
Supports multiple filing statuses and progressive tax calculation.

---

## 📂 Filing Status
| Code | Status |
|------|---------------------------------------------|
| 0    | Single |
| 1    | Married Filing Jointly / Qualifying Widow(er) |
| 2    | Married Filing Separately |
| 3    | Head of Household |
